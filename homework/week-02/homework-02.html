Question 1: Training and test error under a fixed design

Let

\[ \beta_j = 0.4^{\sqrt{j}}, \qquad j = 1, \ldots, p, \]

and keep one simulated design matrix fixed. I generate a single \(n \times p\) matrix, define \(\mu = X_{\mathrm{all}}\beta\), and then generate one training response and one independent test response as

\[ \mathbf y = \mu + \varepsilon, \qquad \mathbf y^* = \mu + \varepsilon^*. \]

The training and test MSEs are computed for each nested model with the first \(m\) predictors. I repeat this 200 times with the same fixed design.

set.seed(43202)
n <- 100
p <- 20
reps <- 200

X_all <- matrix(rnorm(n * p), nrow = n)
beta <- 0.4^sqrt(1:p)
mu <- drop(X_all %*% beta)

train_mse <- matrix(NA_real_, nrow = reps, ncol = p + 1)
test_mse <- matrix(NA_real_, nrow = reps, ncol = p + 1)

for (k in seq_len(reps)) {
  y_train <- mu + rnorm(n)
  y_test <- mu + rnorm(n)

  for (m in 0:p) {
    X_m <- cbind(1, X_all[, seq_len(m), drop = FALSE])
    beta_hat <- solve(crossprod(X_m), crossprod(X_m, y_train))
    y_hat_train <- drop(X_m %*% beta_hat)
    y_hat_test <- drop(X_m %*% beta_hat)

    train_mse[k, m + 1] <- mean((y_train - y_hat_train)^2)
    test_mse[k, m + 1] <- mean((y_test - y_hat_test)^2)
  }
}

expected_train <- expected_test <- numeric(p + 1)
for (m in 0:p) {
  X_m <- cbind(1, X_all[, seq_len(m), drop = FALSE])
  Q <- qr.Q(qr(X_m))
  mu_hat <- drop(Q %*% crossprod(Q, mu))
  bias2 <- mean((mu - mu_hat)^2)
  expected_train[m + 1] <- bias2 + 1 - (m + 1) / n
  expected_test[m + 1] <- bias2 + 1 + (m + 1) / n
}

avg_train <- colMeans(train_mse)
avg_test <- colMeans(test_mse)
train_monotone <- all(apply(train_mse, 1, function(z) all(diff(z) <= 1e-10)))
cat("Monotone training MSE in each repetition:", train_monotone, "\n")

The training MSE decreases or stays the same as predictors are added, because each larger model contains the previous one. The expected test MSE has a bias term that falls as more useful predictors are included and a variance term that rises because more parameters are estimated. This is why test MSE is a better criterion than training MSE for choosing a model.

A single test curve is noisier because it reflects one random response realization, whereas the average test curve smooths out that randomness.

Question 2: Prediction error at one target point

Let

\[ \mathbf x_0 = (0,1,0,0,1,0)^\top, \qquad \mu_0 = \mathbf x_0^\top \beta = 0.5 + 0.5 = 1. \]

For this fixed orthogonal cosine design, the expected squared error at the target is

\[ E\left[(\widehat{\mu}_{0,m} - \mu_0)^2 \mid X_{\mathrm{all}}\right] = \left(\sum_{j=m+1}^{p} x_{0j}\beta_j\right)^2 + \frac{\sigma^2}{n}\left(1 + \sum_{j=1}^{m} x_{0j}^2\right). \]

Only predictors 2 and 5 are active at this target point. The expected squared error therefore changes only when \(m\) reaches 2 or 5. It stays the same in between.

set.seed(43203)
n <- 100
p <- 6
sigma2 <- 1
reps <- 200

i <- 1:n
j <- 1:p
X_all <- sqrt(2) * cos(pi * outer(i, j, function(a, b) b * (a - 0.5) / n))

beta <- rep(0.5, p)
x0 <- c(0, 1, 0, 0, 1, 0)
mu <- drop(X_all %*% beta)
mu0 <- sum(x0 * beta)

sim_sq_error <- matrix(NA_real_, nrow = reps, ncol = p + 1)
theory <- numeric(p + 1)

for (m in 0:p) {
  omitted_signal <- sum(x0[(m + 1):p] * beta[(m + 1):p])
  variance_term <- sigma2 / n * (1 + sum(x0[seq_len(m)]^2))
  theory[m + 1] <- omitted_signal^2 + variance_term
}

for (k in seq_len(reps)) {
  y <- mu + rnorm(n)
  for (m in 0:p) {
    X_m <- cbind(1, X_all[, seq_len(m), drop = FALSE])
    beta_hat <- solve(crossprod(X_m), crossprod(X_m, y))
    pred <- c(1, x0[seq_len(m)]) %*% beta_hat
    sim_sq_error[k, m + 1] <- (pred - mu0)^2
  }
}

avg_sim <- colMeans(sim_sq_error)
plot(
  0:p,
  avg_sim,
  type = "o",
  pch = 16,
  lwd = 2.2,
  col = "#2F6FB3",
  xlab = "Number of predictors m",
  ylab = "Mean squared error at target",
  bty = "l"
)
lines(0:p, theory, lty = 2, lwd = 2, col = "#C84A16")
legend(
  "topright",
  legend = c("Simulation average", "Theoretical expectation"),
  col = c("#2F6FB3", "#C84A16"),
  lty = c(1, 2),
  pch = c(16, NA),
  lwd = 2,
  bty = "n"
)
cat("Smallest m minimizing theory:", which.min(theory) - 1, "\n")
Smallest m minimizing theory: 5

The smallest \(m\) minimizing the theoretical error is \(m=5\). By that point, both relevant target directions have been included, and the squared bias is eliminated. This is a target-specific fact, unlike the average test MSE in Question 1, which is averaged over the whole design.

Question 3: The optimism correction

Let \(H = X(X^T X)^{-1} X^T\) and define

\[ MSE_{\mathrm{train}} = \frac{1}{n}\|y - Hy\|_2^2, \qquad MSE_{\mathrm{test}} = \frac{1}{n}\|y^* - Hy\|_2^2. \]

The expected training MSE is

\[ E(MSE_{\mathrm{train}} \mid X) = \frac{B^2}{n} + \sigma^2\left(1 - \frac{p+1}{n}\right), \]

and the expected test MSE is

\[ E(MSE_{\mathrm{test}} \mid X) = \frac{B^2}{n} + \sigma^2\left(1 + \frac{p+1}{n}\right). \]

Therefore the expected optimism is

\[ E(MSE_{\mathrm{test}} - MSE_{\mathrm{train}} \mid X) = \frac{2(p+1)\sigma^2}{n}. \]

For \(n=120\), \(p=4\), \(B^2/n = 0.04\), and \(\sigma^2=1\),

\[ E(MSE_{\mathrm{train}} \mid X) = 0.04 + 1 - \frac{5}{120} = 0.998333, \]

\[ E(MSE_{\mathrm{test}} \mid X) = 0.04 + 1 + \frac{5}{120} = 1.081667, \]

so the expected optimism is \(0.083333\).

The corrected test MSE estimate is

\[ \widehat{MSE}_{\mathrm{test}} = \frac{RSS + 2(p+1)\widehat\sigma^2}{n}. \]

With \(RSS = 116.4\), \(p=4\), \(n=120\), and \(\widehat\sigma^2 = 0.96\),

\[ \widehat{MSE}_{\mathrm{test}} = \frac{116.4 + 2\cdot 5\cdot 0.96}{120} = 1.05. \]

Also,

\[ C_p = \frac{RSS}{\widehat\sigma^2} - n + 2(p+1) = \frac{116.4}{0.96} - 120 + 10 = 11.25. \]

These quantities are related by

\[ \widehat{MSE}_{\mathrm{test}} = \frac{\widehat\sigma^2(C_p + n)}{n}. \]

Because \(n\) and \(\widehat\sigma^2\) are common across candidate models, minimizing \(C_p\) is equivalent to minimizing the corrected test MSE.

Question 4: Comparing Mallows’ \(C_p\), AIC, and BIC

I use rows 1 through 370 of diabetes.csv as the training data, and I keep rows 371 through 442 aside for the final evaluation described in Question 5.

training <- read.csv("data/diabetes.csv")[1:370, ]
n <- nrow(training)

model_vars <- list(
  A = c("bmi", "bp", "s5", "sex", "s1", "s2", "s4"),
  B = c("bmi", "bp", "s5", "sex", "s1", "s2", "s4", "s6"),
  Full = c("age", "sex", "bmi", "bp", "s1", "s2", "s3", "s4", "s5", "s6")
)

rss_by_model <- sapply(model_vars, function(vars) {
  X <- cbind(1, as.matrix(training[vars]))
  fit <- lm.fit(X, training$y)
  sum(fit$residuals^2)
})

p_by_model <- sapply(model_vars, length)
residual_df_full <- n - (p_by_model["Full"] + 1)
sigma2_hat <- rss_by_model["Full"] / residual_df_full

results <- data.frame(
  model = c("Model A", "Model B"),
  p = p_by_model[c("A", "B")],
  RSS = rss_by_model[c("A", "B")]
)
results$Cp <- results$RSS / sigma2_hat - n + 2 * (results$p + 1)
results$AIC_red <- n * log(results$RSS / n) + 2 * (results$p + 1)
results$BIC_red <- n * log(results$RSS / n) + (results$p + 1) * log(n)

print(c(full_residual_df = residual_df_full, sigma2_hat = sigma2_hat))
print(results)

For the full model, the residual degrees of freedom are

\[ 370 - (10 + 1) = 359, \]

and

\[ \widehat\sigma^2 = \frac{RSS_{\mathrm{full}}}{359} \approx 3034.68. \]

The resulting comparisons are:

Model \(p\) RSS \(C_p\) Reduced AIC Reduced BIC
Model A 7 1,098,908.566 8.116 2,974.640 3,005.948
Model B 8 1,089,717.057 7.087 2,973.532 3,008.754

So \(C_p\) and reduced AIC select Model B, while reduced BIC selects Model A. The reason is that BIC penalizes the extra parameter more strongly. This does not mean one criterion is “right” in a scientific sense; it means different measures use different penalties and therefore different tradeoffs between fit and complexity.

Question 5: Validation and final test data

The first misuse of the final test data is Step 2: after fitting all candidate models, the analyst evaluates each model on the final test data and then chooses the smallest MSE. That selection is already using the test data to tune the model. The minimum of eleven noisy test MSE values is therefore too optimistic as an estimate of future performance.

A valid workflow is:

  1. Keep rows 371 through 442 as the final test set.
  2. Split the training data (rows 1 through 370) into five folds.
  3. For each candidate model size \(m\), fit on four folds and validate on the remaining fold.
  4. Average the five validation MSEs for each \(m\).
  5. Choose the predictor count with the smallest average validation MSE.
  6. Refit the selected model on all 370 training rows.
  7. Evaluate it once on the untouched final test set.

If the analyst has already looked at all eleven test MSE values, they can still describe the results as exploratory. But they cannot call that a clean final estimate of prediction error without a fresh, independent dataset for a new final evaluation.
